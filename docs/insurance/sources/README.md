# Insurance source documents

Archive of the **original** official documents that production insurance data (acts, TNR, rules)
must cite. Nothing here is interpreted; the register records what each document is and where things
are in it.

## Intake (for each supplied document)

1. **Keep the original file unchanged**, named `<source_id>__<short-name>.<ext>`, e.g.
   `SRC-A__loi-65-00.pdf`. Never re-save, OCR in place, compress or rename after hashing.
2. **Checksum**: `sha256sum <file>`, recorded in `REGISTER.md`.
3. **Metadata** in `REGISTER.md`:
   - title, issuing body, document type;
   - publication date, and effective date only if the text states it explicitly;
   - URL and retrieval date;
   - exact page count (`pdfinfo <file> | grep Pages`), language, version.
4. **Type**: one of LAW, DECREE, CONVENTION, TARIFF, NOMENCLATURE, PROCEDURE, FORM, GUIDE.
5. **Source map**: a `<source_id>.map.md` file listing page → subject → provision / table, by
   location only. Ambiguous passages are listed as such, not interpreted.
6. **Status**:

   | Status | Meaning |
   |---|---|
   | `SOURCE_NOT_OBTAINED` | No complete original in this folder |
   | `OBTAINED_UNREVIEWED` | Original archived, hashed and mapped; not yet reviewed |

   Later statuses belong to the ingestion stages.

A search result, press article, excerpt, summary, re-typed copy or a document generated by the app is
**not** a source and is never archived here.

## Not sources (found in the repository, excluded)

The following files on `main` are **not** original official documents. The application generated
them, or they are images of unrecorded origin, so they cannot be cited:

- `public/fse_cnss_remplie_propre.pdf`, `public/fse_cnss_remplie_debug.pdf`: output of the app's
  feuille de soins generator (`scripts/generateCnssTemplatePdf.js`)
- `scratch/calibrated_propre.pdf`, `scratch/calibrated_debug.pdf`: scratch output
- `public/assets/cnss-page1.jpg`, `cnss-page2.jpg`, `FSE_CNSS_page1.jpg`: form images with no
  recorded URL, issuing body or retrieval date
